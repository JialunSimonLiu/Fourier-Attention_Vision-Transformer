# Experimental DP cases (two regimes):
# 1) LCMO-500 nanocrystal: strong-phase, multi-domain case.
#    Sharp phase jumps at domain walls produce split peaks + dense fringes,
#    making phase retrieval highly non-convex and sensitive to initialisation.
# 2) STO crystal: weak-phase reference case.
#    Smoother phase / less distorted diffraction; serves as a sanity check
#    where classical iterative methods are typically stable and reproducible.
# Together these two datasets test both strong-phase robustness (LCMO-500)
# and weak-phase fidelity (STO) under the same reconstruction pipeline.
